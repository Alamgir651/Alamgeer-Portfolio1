# Portfolio1

Premium cinematic developer portfolio built with React, Vite, Tailwind CSS v4, Three.js, React Three Fiber, Drei, GSAP, Framer Motion, Lenis, and postprocessing.

## Commands

```bash
npm install
npm run dev
npm run build
```

## Folder Structure

```text
src/
  assets/        Static project assets
  components/    Reusable React components
    layout/      Page layout pieces
    sections/    Portfolio page sections
    three/       React Three Fiber scenes
    ui/          Small shared UI components
  data/          Editable portfolio content
  styles/        Global CSS and Tailwind import
```

## Content

Update your name, headline, email, social links, services, projects, skills, and stack items in:

```text
src/data/profile.js
```
